## 目标
- 所有入口在交互前统一检查配置完整性（含 Mapping）。
- 配置不完整时强制弹出设置页并禁止其它页面与操作。
- Mapping 改动即时持久化保存，无需手动点击“保存”。

## 中心守卫实现
- 在 `ConfigTools` 中增加统一方法：
  - `GuardAndOpenSettingsOnlyIfIncomplete(MrTerrainPainterWindow win)`：返回布尔值，若不完整则打开设置页并返回 false，完整返回 true。
  - 触发事件 `CompletenessChanged(bool)`，在 `Save` 后广播完整性状态变更，便于各 UI 同步显示。

## 接入入口点
- 窗口类入口：
  - `MrTerrainPainterWindow.OpenWindow`、`OpenPaintingSettingsMenu`、`OpenPaintingSettings`、`BuildControlSection`、`LoadPaintingTab`、`LoadGenerateTab`：调用中心守卫；不完整时只加载 Settings。
- 快捷键/上下文菜单入口：
  - `MTPEntryPoints.ShortcutOpenWindow`（Alt+M）、`ToggleBrushTool`（Alt+B）、`CONTEXT/Terrain/.../Open Window`：在打开或切换前调用中心守卫；不完整时仅打开设置页。
- 工具入口：
  - `MTPBrushTool.OnActivated`：保持不自动打开窗口，但若不完整则调用中心守卫，仅打开设置页并阻止其它操作。
- Overlay：
  - 已用 `PlaseMapping` 按钮触发守卫；订阅 `CompletenessChanged`，在配置保存后即时切换互斥显示（按钮与其它区域）。

## 持久化策略
- Settings 页面：将所有配置改动（Mapping 的 ObjectField / PrefabType / Add / Delete）在变更回调中调用 `ConfigTools.Save`，即改即存，并触发 `CompletenessChanged`。
- NormalDirection：使用 `ConfigTools.SetNormalDirection`（内部 Save + 事件广播），实现事件式联动。

## 互斥显示与禁用
- Overlay 互斥显示：
  - 不完整：显示 `PlaseMapping` 与 `buttonNode`，隐藏 `Other`。
  - 完整：隐藏 `PlaseMapping` 与 `buttonNode`，显示 `Other`。
- 在窗口内：Settings 以外的标签（Painting/Generate）在不完整时禁用，不允许打开；点击任何入口都会被守卫重定向到 Settings。

## 验证
- 删除或置空必须的 UXML/USS，触发不完整：所有入口打开后直接进入 Settings；Overlay 仅显示映射按钮；Brush 工具激活时也只引导配置。
- 在 Settings 修复 Mapping 后：即时保存并广播完整性，Overlay 与窗口互斥显示切换为正常；其它页面与操作恢复可用。

## 说明
- 事件式刷新替代轮询（已为 `BrushSettings` 添加 `Changed` 事件；`NormalDirection` 用 `NormalDirectionChanged`）。
- 保持脚本只管逻辑，UXML/USS 纯视觉；互斥显示与入口禁用通过中心守卫与事件统一管理。
