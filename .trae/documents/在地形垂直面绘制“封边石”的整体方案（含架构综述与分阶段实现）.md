## 目标
- 将封边石统一为 VegetationProfile 项（无需特殊Profile类型），通过 Mapping 中的新类型 “Landscape” 触发封边石规则
- 封边石规则：仅在高坡度（近垂直）面上放置；沿法线方向插入地形；强制法线对齐；保留现有分布与间距约束

## 核心改动
- PrefabType 扩展：在 Runtime/Profiles/PrefabType.cs 增加枚举值 `Landscape`（供 Mapping 选择）
- VegetationItem 属性扩展：
  - `edgeSlopeThreshold`（float，默认 75°）
  - `embedDepthRange`（Vector2，默认 0.1..0.3 米）
- Painter/Generator 行为统一：
  - 在 `BrushPainter.Paint/ PaintMixed` 与 `VegetationGenerator.GenerateOnTerrain` 的放置循环中：
    - 当 `item.prefabType == Landscape`：
      - slope < edgeSlopeThreshold 则提前返回（不放置）
      - 位置插入：`pos -= normal.normalized * embedDepth`（embedDepth 从 `embedDepthRange` 采样）
      - 强制法线对齐（即使全局 normalDirection 关闭）
    - 其余类型使用原有逻辑
  - 保持统一候选上限与网格间距、父节点解析、对象池复用与日志节流

## UI 与配置
- Mapping：SettingsTab 中的类型枚举支持 `Landscape`，可绑定父节点用于封边石归类
- 属性面板：当条目类型为 `Landscape` 时显示并绑定 `edgeSlopeThreshold` 与 `embedDepthRange` 控件
- Overlay：可选增加全局覆盖的“封边石插入深度/坡度阈值”临时参数（优先使用条目级；仅在当前选项为 Landscape 时显示）

## 实施步骤
1) 扩展枚举与数据模型
- 增加 `PrefabType.Landscape`
- 在 `VegetationItem` 增加 `edgeSlopeThreshold` 与 `embedDepthRange` 字段及序列化默认值

2) 行为落地（刷涂与生成）
- `BrushPainter.Paint`/`PaintMixed`：在高度/法线获取后，若 `Landscape`：
  - slope 检查不通过则 continue
  - 插入：计算 embedDepth 并 `pos -= n * embedDepth`
  - 旋转：法线对齐（强制）
- `VegetationGenerator.GenerateOnTerrain`：批量生成路径同样应用上述逻辑

3) UI 绑定
- SettingsTab/PropertyPanel：为 `Landscape` 类型的条目显示与绑定两个新字段
- Overlay（可选）：在当前选中条目为 `Landscape` 时展示“插入深度/坡度阈值”滑条（使用条目级或临时覆盖）

## 验证
- 在近垂直面（高坡度）上刷涂 `Landscape` 条目：
  - 仅高坡区域出现；插入深度与法线对齐正确；撤销/重做与对象池复用正常
- 批量生成：
  - 选中地形内高坡区域批量生成封边石；日志与父节点映射工作正常
