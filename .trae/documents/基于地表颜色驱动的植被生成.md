## 目标
- 采用 RenderTexture 作为地表颜色/分类的数据源，实现高效、可视化可控的植被生成筛选
- 在编辑器内完成一次 RT 烘焙与读取，生成时快速采样匹配

## RT 数据源方案
- 顶视正交烘焙：创建一个正交相机对地形区域进行顶视渲染到 RT
- 着色器输出
  - 颜色模式：输出最终合成颜色（地形材质 + splat 叠加），用于后续色差匹配
  - 分类模式（推荐）：按规则输出类别索引（如 R/G/B/A 编码或整型写入），避免后续颜色阈值比较，更高效与鲁棒
- RT 配置：分辨率（如 1024-2048）、覆盖 Bounds（单地形或合并多地形）、FilterMode = Point（分类）/ Bilinear（颜色）、Read/Write 支持

## 坐标与采样
- 世界坐标 → RT 像素坐标
  - 根据烘焙相机的投影矩阵与 Bounds，将世界 XZ 映射到 RT UV（0..1）
  - 映射到像素索引：`px = floor(u * width)`, `py = floor(v * height)`
- 读取策略
  - 编辑器离线：使用 `AsyncGPUReadback` 将 RT 读回 CPU 缓存（byte[]/Color32[]），首次烘焙后一次性完成
  - 生成时：直接索引缓存而非每次调用 GetPixel，性能稳定

## 策略与规则
- 分类模式（推荐最佳实践）
  - 在烘焙 shader 中按 TerrainLayer 或自定义规则输出类别 ID
  - `FilterSettings.ColorRTSettings` 持有 RT 与类别→植被条目/PrefabType 的映射表
  - 生成验收：读取像素类别 ID，若映射命中则接受；支持阈值或概率加权
- 颜色模式
  - 输出合成颜色到 RT
  - `FilterSettings.ColorPaletteRules`：HSV/Lab 调色板 + 容差，进行色差匹配（可转为概率）
  - 不可读或特殊材质时回退 Layer 模式

## 集成流程
- Generate 管线：
  1) 分布采样 → `TryGetHeightAndNormal`
  2) 颜色/分类 RT 采样验收（提前返回）
  3) 高度/坡度匹配 → 最小间距 → 实例化
- Paint 管线：
  1) 预览与边缘接受度 → RT 验收（提前返回） → 其余一致

## UI 与配置
- 生成页新增“颜色/分类 RT”分组：
  - Toggle：启用
  - 选择模式：`分类 | 颜色`
  - RT 引用字段 or “烘焙”按钮（自动创建 RT 并写入）
  - 分辨率与 Bounds 设定（默认当前地形范围）
  - 分类模式：类别到条目映射表编辑器（ListView）
  - 颜色模式：调色板规则（ColorField/HSV + 容差）

## 验证与性能
- 单次烘焙耗时可控（1024² 级别），生成阶段采样为 O(1)
- 多地形：可为每个地形烘焙独立 RT 或合并到统一大图（带地形索引编码）
- 异常与回退：RT为空或越界 → 回退 alphamap 或按默认通过/默认拒绝策略
