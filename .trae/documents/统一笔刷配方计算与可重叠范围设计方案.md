# 问题与目标
- 预览圆形范围随摄像机距离变化：命中非地形碰撞体/预览绘制未按地形法线导致视觉不稳定。
- 场景绘制交互不够现代：事件处理与预览绘制耦合、未区分 Layout/Mouse/Repaint。
- 目标：预览稳定（世界单位一致、与地形法线对齐、遮挡正确）、交互优雅（现代 EditorTool/事件分层）、美观（抗锯齿圆环）。

## 设计方案
### 1. 命中定位与法线对齐
- 射线定位：仅命中地形
  - 使用 `LayerMask` 限制到 Terrain/地面图层，或遍历 `Terrain.activeTerrains` 计算命中点：将鼠标屏幕坐标转世界射线→对各 Terrain 的包围盒进行粗测→再用 `TerrainData.GetHeight/InterpolatedNormal` 获取精确地形高度与法线。
  - 参考：`Editor/MrTerrainPainterWindow.cs:617–680`（当前使用 `Physics.Raycast` 可命中树/石头等）。
- 法线对齐：
  - 预览圆盘使用 `Handles.DrawWireDisc(center, terrainNormal, radius)` 或抗锯齿折线绘制圆环，法线由地形采样获得（`TerrainUtils.TryGetHeightAndNormal`）。

### 2. 事件分层（最佳实践）
- `SceneView.duringSceneGui` 中分三阶段：
  - Layout：`HandleUtility.AddDefaultControl` 拦截选择；避免与场景选择冲突。
  - Mouse（Down/Drag/Move）：更新笔刷中心与模式（Paint/Erase/Generate）。
  - Repaint：仅绘制预览（圆环/填充）。确保预览不随事件噪声重复绘制。
- 参考点：`Editor/MrTerrainPainterWindow.cs:606–680`（当前在 MouseDown/Drag 同时绘制预览）。

### 3. 预览绘制美观稳定
- 抗锯齿圆环：`Handles.color` 透明色 + `Handles.DrawAAPolyLine` 自行采样 64–128 点圆，或使用 `Handles.DrawSolidDisc` + 外环线。
- 遮挡正确：设置 `Handles.zTest = UnityEngine.Rendering.CompareFunction.LessEqual`，让圆盘受场景遮挡影响更自然。
- 仅在 `EventType.Repaint` 绘制，避免闪烁与重复。
- 预览半径保持世界单位；视觉变化是透视造成但范围不变（与地形法线对齐可改善感知）。

### 4. 交互现代化（可选增强）
- 使用 `EditorTool`（`UnityEditor.EditorTools`）实现笔刷工具：
  - 工具启停更优雅；快捷键切换；与 Unity 工具栏一致。
  - 在 `EditorTool.OnToolGUI` 内按上述事件分层调用。
- 提供 SceneView Overlay：显示当前笔刷参数与快速切换。

### 5. 实施步骤与改动点
- 文件：`Editor/MrTerrainPainterWindow.cs`
  1) 替换 `Physics.Raycast` 为“仅地形定位”方法：优先 Terrain 包围盒粗测→`TerrainUtils.TryGetHeightAndNormal` 精确采样；若鼠标下无地形，回退最近地形（已有 `NearestTerrain`）。
  2) 在 `OnSceneGUI` 分流：`Layout` 拦截、`Mouse` 更新状态、`Repaint` 调用 `BrushPainter.DrawPreviewAt(center, normal, radius)`。
- 文件：`Editor/Services/BrushPainter.cs`
  3) 新增 `DrawPreview(Vector3 center, Vector3 normal, float radius, BrushSettings)`：使用 `Handles.zTest`、`DrawSolidDisc + DrawAAPolyLine`，法线对齐，仅供 Repaint。
- 文件：`Editor/Utils/TerrainUtils.cs`（若存在）
  4) 添加 `RaycastToTerrain` 辅助：从鼠标射线→返回 `center/normal/terrain`，不命中其他碰撞体。
- 可选：新增 `BrushEditorTool.cs` 实现工具化；保留现有入口作为回退。

### 6. 验证
- 在含大量静态碰撞体（树、石头）场景下，预览始终落在地形上；圆盘随地形坡度对齐；远近摄像机预览范围一致（世界单位），视觉稳定。
- 在不同模式（Paint/Erase/Generate）下，预览仅在 Repaint 绘制；鼠标拖动流畅无闪烁；遮挡表现自然。
